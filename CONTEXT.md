# CONTEXT — LA Fat Segmentation

## Glossary

- **LA Fat** — Left Atrial Epicardial Adipose Tissue. All epicardial fat partitioned to the left atrium. Shorthand: "LA fat."
- **Epicardial Fat** — Adipose tissue between the heart muscle (myocardium) and the pericardium (the sac around the heart). Not mediastinal fat, not visceral fat.
- **TotalSegmentator (TS)** — An off-the-shelf deep-learning model that segments 100+ anatomical structures from CT scans. Used here for anatomical localization, not for fat segmentation itself.
- **Pericardium** — The fibrous sac surrounding the heart. The outer boundary for epicardial fat — fat outside this is not epicardial.
- **Partition Anchors** — The six structures whose surfaces form the basis for assigning fat voxels: {LA, LV, RA, RV, Aorta, Pulmonary Artery}. Pulmonary veins are excluded as a partition target (their surrounding fat belongs to LA).
- **Partition** — The assignment of each epicardial fat voxel to the nearest anchor structure, based on distance from the voxel to each anchor's surface. Replaces explicit anatomical exclusions, mitral plane cutoffs, and superior buffers with a single distance-based principle.
- **HU (Hounsfield Units)** — CT intensity scale. Fat typically sits in the negative range (~-190 to -30 HU), but the exact range varies by scanner, contrast protocol, and patient habitus.
- **Per-Patient Fat Threshold** — A single Gaussian fitted to the sub-0 HU voxel distribution within the pericardium. The fat range = mean ± 2σ, then **clamped** to the fixed fallback range (-190 to -30 HU). Clamping one or both tails (fit succeeded but range exceeded the fallback bounds) is a low-concern flag; a **full fallback** (Gaussian fit failed entirely — too few voxels, sigma too large, or inverted range) is a high-concern flag. Simpler than GMM: one peak, no class-swapping, no seed initialization.
- **TS Pre-Compute** — TotalSegmentator runs as a separate, GPU-dependent pre-processing step. Masks are saved to disk once. The fat extraction pipeline is pure CPU and can be re-run with different parameters without re-running TS. Matches the "validate TS first" goal.
- **QA Dashboard** — Per-scan and cohort interactive QA studio. A zero-footprint standalone browser application (`cohort_qa_dashboard.html`, pure HTML5/Canvas/WebGL) with: (1) a Cohort Scorecard matrix with quality badges and 5-landmark slice filmstrips, (2) a Multi-Planar PACS viewer (Axial, Coronal, Sagittal) with synchronized scrubbers, 6-channel layer toggles, and curtain wipe against native CT, and (3) a 3D WebGL Studio with rotatable cardiac meshes, surface opacity controls, and camera presets. 100% offline, zero runtime server or npm dependencies. Replaces previous Panel/PyVista and static Matplotlib viewers.
- **Mesh** — A 3D surface (vertices + faces) rendered directly in WebGL within the QA Dashboard without requiring pre-computed Marching Cubes `.ply` disk files.
  _Avoid_: 3D model, surface model
- **Dual-Grid Radiomics Masks** — Simultaneous extraction and export of both 1.5mm isotropic screening masks and native-grid (512x512, ~0.35mm) binary masks preserving raw CT DICOM affine headers for IBSI-standardized PyRadiomics texture feature analysis.
- **Segmentation Result** — The consolidated immutable result object containing all computed volumes (adaptive and conservative dual-window), Gaussian fit parameters, quality flags, 3D binary masks, and QA records.
- **Quality Flags** (not a collapsed score) — **High concern:** pericardium fallback triggered, anchor mask missing or below volume threshold, fat threshold fell back to fixed range (Gaussian fit failed entirely). **Medium concern:** LA fat volume outside 2–60ml, LV/LA fat ratio exceeds 4.0, >80% of pericardial fat unassigned, total epicardial fat below 8% of pericardium volume (possible contrast CT or loose pericardium mask). **Low concern:** wide Gaussian σ (>100 HU), per-patient HU range clamped to fallback bounds at one or both tails (fit succeeded but tails were cut). Each flag reported separately; the user evaluates, not a magic number.
  _Note:_ Small-island cleanup is always performed but no longer generates a quality flag (count and volume remain in the summary CSV).
- **Canonical Patient ID** — The 4-digit zero-padded slug (e.g., `0674`, `1512`, `2996`) used uniformly as the primary key across filesystem paths, intermediate arrays, QA reports, and radiomics output.
- **Cohort Manifest** — A version-controlled metadata registry mapping canonical patient IDs to demographic fields, acquisition metadata, raw DICOM tags, and scanner software measurements.
- **Scanner Software Baseline** — Reference EAT and LA-EAT volumes extracted by the clinical CT scanner software. Used for correlation analysis and sanity auditing, not as an exact ground-truth pass/fail gate.
- **Anatomical Mask Cache** — Pre-computed TotalSegmentator multi-label anatomical segmentation masks stored on local storage (`masks/{patient_id}/`) outside the git repository to decouple GPU inference from CPU fat extraction.
